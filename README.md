# portal6-ics

Ce dépôt ne contient que les fichiers `.ics` publiés — il n'est pas édité à la main.

|---|---|
| LEC (LoL) | `https://raw.githubusercontent.com/frgrz-pro/portal6-ics/main/lol/lec.ics` |
| LCK (LoL) | `https://raw.githubusercontent.com/frgrz-pro/portal6-ics/main/lol/lck.ics` |
| LoL international | `https://raw.githubusercontent.com/frgrz-pro/portal6-ics/main/lol/international.ics` |
| CS2 | `https://raw.githubusercontent.com/frgrz-pro/portal6-ics/main/cs2/main.ics` |

Google Calendar : « Autres agendas » → « + » → « À partir de l'URL ».
